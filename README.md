Banco de Dados para Supermercado

Este repositório contém o projeto de um banco de dados desenvolvido em grupo para um supermercado. Utilizando o MySQL, o banco de dados foi estruturado para gerenciar informações como produtos, clientes, vendas e estoques. O projeto visa otimizar o controle interno de dados e processos de um supermercado, oferecendo uma base sólida para operações de consulta e atualização eficientes.
